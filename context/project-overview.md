# Project Overview: KeepChat (PromptVault)

## Mission
KeepChat is a centralized storage tool for users to effortlessly save, organize, categorize, search, and review outputs generated by AI models (ChatGPT, Gemini, Claude, DeepSeek, etc.).

## Core Philosophy & Layout
- **Visual Vibe**: WhatsApp Web meets Google Gemini typography.
- **Desktop (>768px)**: Persistent two-pane view with fixed-ratio sidebar (~30%) and rich content pane (~70%).
- **Mobile (<768px)**: Native Android WhatsApp single-pane flow. Screen 1 shows the chats list with Floating Action Button. Tapping any chat smoothly slides into the full-screen thread view with a top native Back button.
- **Formatting Fidelity**: 100% Markdown preservation including GitHub Flavored Markdown (GFM) tables, lists, blockquotes, code blocks with syntax highlighting and 1-click copy buttons.
- **Offline & Instant**: Local storage persistence with import/export capabilities.
